# Beauty Connect Automation

This project is for Beauty Connect (beautyconnectshop.com) and automates the process of adding qualified leads from Shopify to their CRM (currently GoHighLevel), and starting conversations through WhatsApp using a custom AI agent. This automation is a collaboration between Systemify Automation and One Umbrella.

## Overview

When a lead is approved in Shopify, this automation:
1. ✅ Captures the lead data via webhook
2. ✅ Creates/updates the contact in GoHighLevel CRM
3. ✅ Initiates a personalized WhatsApp conversation
4. ✅ Starts the AI-powered engagement process

## Quick Start

1. **Read the Strategy** - Review [STRATEGY.md](./STRATEGY.md) to understand the automation workflow
2. **Prepare Requirements** - Gather API keys and credentials from Shopify, GoHighLevel, and WhatsApp
3. **Import Scenario** - Follow [SETUP-GUIDE.md](./SETUP-GUIDE.md) to import and configure the Make.com scenario
4. **Test** - Run test executions to verify the automation works correctly
5. **Go Live** - Enable the scenario and monitor initial executions

## Requirements

- **Make.com** account (Free or paid plan)
- **Shopify** store with admin access
- **GoHighLevel** account with API access
- **WhatsApp Business** account connected to GoHighLevel

## Key Features

- 🔄 Automatic lead synchronization from Shopify to GoHighLevel
- 📱 Instant WhatsApp message delivery to approved leads
- 🏷️ Automatic tagging and custom field population
- 📊 Error handling and execution logging
- ⚡ Real-time webhook-based triggering
- 🔒 Secure API key management
